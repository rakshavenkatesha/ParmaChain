# Recommended Tech Stack

## Frontend

* **React.js** – User Interface
* **Tailwind CSS** – Styling and Responsive Design
* **React Router** – Navigation and Routing
* **Axios** – API Communication
* **Chart.js** – Analytics and Dashboard Charts

---

## Backend

* **Node.js** – Runtime Environment
* **Express.js** – REST API Development

---

## Database (Off-Chain Storage)

* **MongoDB Atlas (Free Tier)** – Store users, drug details, reports, notifications, and analytics
* **Mongoose** – MongoDB Object Modeling

---

## Blockchain

* **Solidity** – Smart Contract Development
* **Hardhat** – Smart Contract Development and Testing Framework
* **Ethers.js** – Blockchain Interaction Library

---

## Blockchain Network

* **Hardhat Local Network** – Development and Testing
* **Ethereum Sepolia Testnet** or **Polygon Amoy Testnet** – Final Demonstration Deployment

---

## Wallet Integration

* **MetaMask** – Blockchain Wallet for Transaction Signing

---

## Authentication & Security

* **JWT (JSON Web Token)** – Authentication
* **bcrypt.js** – Password Hashing

---

## QR Code System

* **qrcode (npm package)** – QR Code Generation
* **html5-qrcode** – QR Code Scanning

---

## File & Document Storage

* **Cloudinary (Free Tier)** – Store Licenses and Documents

---

## Notifications

* **Nodemailer** – Email Notifications

---

## Development Tools

* **Git** – Version Control
* **GitHub** – Source Code Repository
* **Postman** – API Testing
* **Visual Studio Code (VS Code)** – Code Editor

---
